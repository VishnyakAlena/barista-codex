# Мой проект на Express.js

Простой веб-сервер, созданный на платформе Node.js с использованием фреймворка Express.

## 🚀 Как запустить проект локально

### 1. Клонирование репозитория (или скачивание)
```bash
git clone https://github.com/VishnyakAlena/barista-codex.git
cd barista-codex
```

### 2. Установка зависимостей
Установите все необходимые пакеты (включая Express):
```bash
npm install
```

### 3. Запуск сервера
Запустите проект с помощью Node.js:
```bash
npm start
```
После этого откройте в браузере: [http://localhost:3000](http://localhost:3000) (или ваш порт).

## 🛠️ Стек технологий
* Node.js
* Express.js
